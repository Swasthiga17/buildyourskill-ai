# 🌱 GrowSkill AI

> **Learn Smarter. Grow Faster.**

> **Don't learn everything. Learn what you need next.**

GrowSkill AI is an AI-powered personal learning and career mentor that understands what you know, identifies your skill gaps, and continuously guides you toward becoming an AI/ML Engineer.

## Workspace Target
- Primary Path: `D:\myproj1\buildyourskill ai`

## Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts, Lucide React.
- **Backend**: FastAPI, Python 3.11, SQLAlchemy, Pydantic v2.
- **Database**: PostgreSQL + pgvector (Primary relational & vector store).
- **Knowledge Graph**: Neo4j.
